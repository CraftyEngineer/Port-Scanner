# 🔍 Python Port Scanner

A simple Python-based Port Scanner that allows you to scan a target host for open TCP ports through a Command-Line Interface (CLI) or a GUI using Tkinter.

---

## 🚀 Features

- Scan a given IP address or hostname
- Specify port range to scan
- Displays list of open ports
- Simple GUI interface (Tkinter)
- Built using Python sockets

---

## 🧰 Requirements

- Python 3.x

## 🚀 How to Start the Project

Follow the steps below to clone and run the project on your local machine:

1. Clone the repository:  
   ```bash
   git clone https://github.com/CraftyEngineer/Port-Scanner.git
   cd Port-Scanner
   ```
2. Create and activate a virtual environment:  
   ```bash
   python -m venv venv
   source venv/bin/activate  # For Linux/macOS
   venv\Scripts\activate     # For Windows
   ```
3. Install the necessary packages:  
   ```bash
   pip install asyncio aiohttp tk colorama
   ```
4. In the terminal, type:  
   ```bash
   python port_scanner.py
   ```
